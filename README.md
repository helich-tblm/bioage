# Учебный сайт по эндокринологии

## Запуск
1. Распакуйте папку проекта.
2. Откройте `index.html` в браузере.
3. Для удобной разработки можно открыть папку в VS Code и запустить через расширение Live Server.

## Файлы
- `index.html` — структура и содержимое секций.
- `style.css` — все стили, сетки, цвета и адаптивность.
- `script.js` — мобильное меню и поведение FAQ.
- `images/` — сюда добавляются фотографии.

## Замена фотографий
Сохраните свои изображения в `images/` под именами:
`hero.jpg`, `header.jpg`, `section-01.jpg`, `section-02.jpg`, `section-03.jpg`,
`wide.jpg`, `material-01.jpg`, `material-02.jpg`, `material-03.jpg`.

Пока изображений нет, будут видны цветные заглушки/фоновые заливки.


## Фон шапки сайта
Чтобы поставить фотографию на фон верхней шапки с логотипом и меню, добавьте файл `header.jpg` в папку `images`. Для лучшей читаемости меню поверх фото автоматически накладывается тёмный полупрозрачный слой.

## Форма записи
Форма пока демонстрационная: она проверяет обязательные поля, но не отправляет и не сохраняет персональные данные. Для реального сбора заявок нужно отдельно подключить серверную обработку или безопасную интеграцию с Google Таблицей, настроить уведомления и разместить корректную политику обработки персональных данных.
